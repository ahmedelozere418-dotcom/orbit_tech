# Orbit_Tech — نظام كاشير ونقاط بيع POS

موقع تعريفي لنظام **Orbit_Tech** المتكامل لإدارة المبيعات ونقاط البيع (POS) في مصر والسعودية والإمارات والكويت.

## 📁 هيكل الملفات

```
├── index.html              ← الصفحة الرئيسية (كل محتوى الموقع)
├── style.css               ← الأنماط الإضافية
└── assets/
    └── images/             ← صور الموقع
```

## 🚀 التقنيات المستخدمة

- **HTML5** — بنية الصفحة الرئيسية
- **Tailwind CSS** (CDN) — التصميم والتخطيط
- **CSS** — أنماط إضافية مخصصة
- **Google Fonts** — خطوط Cairo و Tajawal
